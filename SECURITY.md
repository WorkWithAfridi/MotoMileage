# Security policy

## Supported versions

Security fixes are intended for the latest version on the default branch. Please update to the latest release before reporting an issue.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://github.com/WorkWithAfridi/MotoMileage/security/advisories/new) to contact the maintainers. If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile.

Include the affected version, steps to reproduce, and potential impact. Do not include real personal data, production backups, or credentials in a report.
